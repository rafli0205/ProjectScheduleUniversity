# Schedule University

## Identitas
- Nama: Rafli Dhiya Padoli
- NIM: 312451

Aplikasi Android untuk membantu mahasiswa mengatur jadwal kuliah agar lebih mudah, cepat, dan terorganisir.

## Fitur
- Splash Screen (deteksi lokasi + greeting sesuai daerah).
- Home: Jadwal hari ini.
- Detail jadwal (tap item untuk lihat dosen/ruang/jam).
- Tambah jadwal.
- Lihat jadwal satu pekan.
- Edit jadwal.

## Tech Stack
- Kotlin
- Android Studio
- (Tambahkan: Room Database / RecyclerView / Material Design, kalau memang dipakai)
